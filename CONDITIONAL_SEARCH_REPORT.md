# Технический отчёт: один дополнительный факт перед поиском заключений

Исторический отчёт первого варианта условного поиска. В текущей локальной
версии добавлены ослабления: см. CONDITIONAL_EXTENDING.md и
CONDITIONAL_EXTENDING_REPORT.md. Числа ниже относятся к прежнему испытанию.

## Изменения

Ядро — C#. Python запускает процессы, ведёт очередь и хранит результаты.
На каждом шаге численного решателя обмена с Python нет.

`ProblemGenerator.Generate` без `GEOGEN_CONDITIONS_CONFIG` возвращает прежний
поток без дополнительного перебора. При включении режима
`ConditionalSearchEngine.Wrap` пропускает промежуточные результаты и исследует
конфигурации последней разрешённой глубины. Дерево построений, ограничения
симметрии конфигураций и ранговые интервалы до этой точки прежние.

Для каждой конечной конфигурации:

1. Вычисляются шесть обычных независимых картинок. Перечисляются тройки точек,
   четвёрки точек, пары прямых и пары отрезков для пяти типов условий.
   Типы чередуются; порядок объектов перемешивается с воспроизводимым seed.
2. Условие, не отличающееся от тождества хотя бы на двух обычных картинках,
   пропускается. Для остальных запускается `ConditionalSampler`.
3. A=(0,0), B=(1,0), C=(x,y). `ConditionalPredicate` возвращает знаковую
   нормированную невязку f(x,y). Производные считаются центральными разностями
   с h=10⁻⁵. Шаг: Δ=−f∇f/(||∇f||²+10⁻¹²); длина шага не больше 0.4.
   Если невязка не уменьшается, шаг последовательно делится пополам до 1/128.
   Каждый расчёт f пересчитывает всю конфигурацию штатным C#-конструктором.
4. При |f|<10⁻¹² сохраняется регулярный корень. Требуются различные формы
   треугольника: расстояние между (x,y) не меньше 0.04 по умолчанию.
   При слишком малом градиенте, совпадающих объектах, неопределённых/чрезмерно
   больших объектах картинка не принимается. По умолчанию нужны восемь корней.
5. На этих картинках вызывается полный `FindAllTheorems`: условие может
   породить факт даже только о старых объектах. Повтор посылки и факты обычной
   конфигурации удаляются. Для каждого оставшегося заключения требуются два
   обычных положения, где **одновременно** неверны условие и заключение.
   Последний объект должен явно участвовать в условии либо заключении.
6. Прувер получает обычные факты, подтверждённые на новых картинках, и одну
   дополнительную посылку. Доказуемые следствия отбрасываются. В условном
   режиме отключены предположение истинности упрощаемых задач и перенос
   теорем по симметрии. Симметрия задачи проверяется для пары «условие,
   заключение». Старое поведение вне условного режима сохранено.
7. Очередь вызывает отдельный C#-верификатор. Он независимо повторяет поиск
   восьми корней с другим seed, проверяет заключение и ищет два контрпримера
   без условия на 12 обычных картинках. Координаты генератора не считаются
   сертификатом. Неудачный подбор не превращается в успешную проверку.

## Передача результатов

`ConditionalProblemData` хранит посылку, найденные формы треугольника,
настройки и обычные пробы. Метаданные проходят через анализатор, ranked JSON,
читаемый вывод и события очереди. Ключи сортировщика и семейной дедупликации
включают совместно посылку и заключение: их нельзя независимо переименовать
и случайно склеить разные задачи.

Конвертер использует первую найденную форму треугольника; посылка рисуется
синим. Geometry показывает дополнительное условие в списке/полном тексте.
Headless-проверка Geometry отдельно проверяет пять видов посылок на реально
вычисленных им объектах. Допуск 0.002 обусловлен арифметикой Float внутри
Geometry; это проверка изображения, а не сертификат истинности.

Проверяющий C#-процесс и JVM-конвертер пока запускаются отдельно для каждой
находки. На большом потоке очередь может обрабатываться существенно дольше
самого поиска. В генераторе этого межпроцессного обмена нет. Ускорение очереди
следует делать пакетной обработкой или постоянными рабочими процессами,
сохраняя изоляцию ошибок и реальные таймауты.

## Что установлено тестами

- 305 C#-тестов из чистого дерева прошли; в том числе подбор условия,
  контрпримеры без него, вырожденный треугольник, JSON round trip,
  различение посылок при сортировке и запрет переноса посылки по симметрии.
- 108 Python-тестов прошли; в том числе отсутствие передачи условной задачи
  в обычный Extending, совместная дедупликация, учёт объектов посылки,
  сохранение конфигурации условий в семейной кампании и её resume.
- Контроль C#: AB=AC ⇒ A,O,H коллинеарны принят на восьми различных картинках,
  сохранены два контрпримера без условия. Ложное заключение AB⊥AC опровергнуто.
  OA=OB не признано условной находкой: оно верно без условия. Повтор посылки
  отклонён. Ограничение в 1 мс даёт timeout.
- Чистые закреплённые исходники собраны с 21 патчем; Haskell regression прошёл.
  При smoke обнаружено несовпадение `condition: null` и отсутствующего поля в
  Python-проверке структуры. Оно исправлено и покрыто тестом; повторный полный
  smoke прошёл, включая старую семейную кампанию (9 ready, 42 duplicate).
- Проверены все 1665 готовых чертежей. Найдены и исправлены восемь ошибок
  старого значка прямого угла: его вспомогательная прямая под 45° оказывалась
  параллельной стороне угла. Теперь используются пересечения сторон угла
  с окружностью вокруг вершины; все 1665 чертежей прошли headless-проверку
  вместе с проверкой выполнения посылки в Geometry. Повреждённый witness
  корректно отклоняется. Случай с прямым углом под 45° включён в smoke.

## Поисковый эксперимент

Вход: треугольник, его центры описанной/вписанной окружностей и ортоцентр
(шесть исходных точек); одна итерация, проекция на прямую или ортоцентр тройки.
Режим GenerateBothSymmetricAndAsymmetric. Пять типов дополнительных условий.
Бюджет 120 с, восемь картинок, 32 начальных приближения и 40 шагов на одно
приближение. Это параметры испытания; штатные пределы — 80 и 60.

Из trace: 3 конечные конфигурации; 1497 условий; 25 общих тождественных
условий пропущено; для 813 условий получены картинки; 656 подборов не дали
достаточно корней. Ещё три базовых условия коллинеарности A,B,C
отброшены как вырождение исходного треугольника. Выполнено 1 638 954 пересчёта картинки и 255 693 шага
решателя. Найдено 17 195 фактов до фильтров, 3335 удовлетворили локальной
проверке существенности. Время генерации 120.039 с.

Запуск выполнялся вместе с проверкой очереди и сборкой на общей машине;
это функциональное испытание, не изолированное измерение скорости.
После прувера в очередь поступило 1698 событий: 1665 ready, 30 review
(найдены условные контрпримеры при независимом подборе), 3 standard.
Поиск вместе с полной обработкой очереди занял 1061.627 с, то есть около
17.7 минуты. Это не 120-секундный полный запуск: 120 с — только генератор.
Медиана времени отдельного проверяющего процесса — 0.5593 с; заметная часть
затрат приходится на запуск процессов и JVM-конвертацию. Из 1668 отчётов
качества 719 содержат структурно неиспользуемые определения. Подробности —
в приложенном summary.json.

## Оценка качества и ограничения

Механизм действительно находит утверждения, которые возникают после добавления
условия и имеют контрпримеры без него. Этого недостаточно для хорошей задачи.
Среди результатов много условий, сводящих треугольник к равнобедренному, и
переформулировок одних и тех же следствий. Есть лишние построения. Оценка
красоты GeoGen пока относится к заключению и не откалибрована для посылки.

Обычные ослабления Extending для условных задач **не реализованы**. Их нельзя
запускать над заключением без посылки: это проверка другой задачи. Вместо
этого новый маршрут проверяет условную истинность и существенность условия;
он явно сообщает об отсутствии проверки ослаблений. Следующий полезный шаг —
при ослаблении построения заново подбирать картинки с той же посылкой и
проверять заключение, а также объединять эквивалентные дополнительные условия.

Поддерживается только Triangle. Область подбора ограничена; совпадающие
построенные объекты исключаются. Некоторые осмысленные условия поэтому
пропускаются. Восемь корней не гарантируют охват всех компонент множества
решений. Формального доказательства нет. Утверждения остаются численными
гипотезами; сложности уровня IMO и новизны этот эксперимент не устанавливает.
