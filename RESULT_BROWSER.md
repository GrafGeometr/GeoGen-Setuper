# Просмотр отбракованных находок и таймаутов

Доработка входит в ветку feature/family-discovery. Команды обновления и сборки
актуального комплекта — в METRIC_THEOREMS.md.

В левой панели Geometry вместо флажка «Только готовые» используется меню
«Раздел»: Готовые, Отбракованные, Таймауты, Нужна проверка, Очередь и ошибки,
Все находки. Отбракованные включают rejected, standard и duplicate; причина
и конкретный статус остаются видны. Таймауты выделены отдельно и не считаются
отбраковкой. Внутри каждого раздела сохранены темы, рейтинги и стабильный
порядок поступления. Выбор раздела явно меняет отображаемый список.

У любой находки доступна кнопка «Условие»: исходная конфигурация и утверждение,
текст можно выделить и скопировать. У готовых задач есть также «Чертёж».
Для rejected/timeout без .geo автоматически показывается условие и полная
причина статуса. Эта версия не строит им чертежи: она не запускает конвертер
и дополнительные проверки ради просмотра отбракованной находки.

Сборка из исходного архива:

```bash
tar -xzf GeoGen-Setuper-result-browser.tar.gz
cd GeoGen-Setuper-result-browser
bash build.sh build --output ./dist/geometry-suite-browser --jobs 2 --test
```

Если инструменты/системные зависимости ещё не установлены, сначала выполните
bash build.sh deps. Для прежнего кэша можно добавить --state /путь/к/.builder.
Указывайте новый output сборки. Запуск обычный:

```bash
./dist/geometry-suite-browser/geometry-suite run ./stories/hard.txt \
  --search-config ./4.json --output ./runs/hard-browser \
  --workers 1 --check-ms 5000 --standard-checks --quality-checks --view
```

Старый завершённый запуск:

```bash
./dist/geometry-suite-browser/geometry-suite watch ./runs/hard
```

watch восстанавливает тексты из tasks.sqlite. При работающем старом
обработчике он не переписывает манифест под чужой блокировкой; viewer пробует
читать уже существующий tasks/<id>/check.geo или theorem.txt. Для полной
миграции дождитесь завершения старого запуска и откройте его повторно.

Технически Queue.export один раз создаёт conditions/<sha256(id)>.txt для
каждой находки, независимо от её статуса. Повторный экспорт не переписывает
готовые условия. results.tsv сохраняет прежние первые девять полей и
добавляет десятое — относительный путь к условию; при выключенных quality-checks
поля 8–9 заполняются unverified и пустым значением. Старый viewer игнорирует
добавленный столбец. Новый reader поддерживает прежние манифесты.

Новые тексты читаются асинхронно только при выборе находки/изменении статуса.
Нет повторного поиска, вызовов Extending или конвертера. Пути ограничены
подкаталогами conditions и tasks каталога запуска; чтение снаружи запрещено.

Проверки: 95 тестов Python; сборка Geometry и Kotlin-проверки старого/нового
манифеста, групп статусов, полного условия и ограничения путей. Интерактивный
просмотр GUI в этой сессии не выполнялся. Полный smoke прошёл: генератор,
конвертер, Extending, потоки и семейная кампания (9 ready, 42 duplicate).
