# Условный поиск для всех стартов GeoGen

Дата проверки: 24 ноября 2026 года.

## Изменения

Три новых патча применяются после опубликованного условного Extending:
`conditional-layouts-geogen.patch`, `conditional-layouts-geometry.patch`,
`conditional-layouts-haskell.patch`. Оболочки и smoke обновлены в сборщике.
Исходные закреплённые репозитории изменять вручную не требуется.

`ConditionalLayout` задаёт размерность, стартовые приближения и численные
начальные объекты. Конструктор пересчитывает прежний DAG. Условный генератор,
независимый валидатор и Extending используют один sampler.

| Старт | Параметры формы |
|---|---:|
| Triangle | 2 |
| RightTriangle | 1 |
| Quadrilateral | 4 |
| CyclicQuadrilateral | 3 |
| LineAndTwoPoints | 2 |
| LineSegment | 0 |
| LineAndPoint | 0 |

Размерность Extending равна размерности формы плюс параметрам ослабленного
объекта. Повторная проверка исходной задачи использует только начальную часть
этого вектора. Количество исходных объектов больше не зашито как три.

Добавлены ослабления `RightTriangle → Triangle` и
`CyclicQuadrilateral → Quadrilateral`. Они учитываются в полноте отчёта наравне
с заменами определений. В контролях условное равенство AB=AC позволяло убрать
прямоугольность, а AB=BC — вписанность: обе отбраковки найдены через
`initial-layout`, с двумя сериями и нарушением прежнего начального ограничения.

Для прямых в конечных разностях нормали локально согласуются со знаком
текущей нормали. Иначе канонический знак около горизонтальной прямой может
создать скачок невязки и нулевой симметричный градиент вместо сходимости.

Снято ограничение семейных кампаний на Triangle. Оба читателя условных `.geo`
распознают все стартовые типы. Обычный Haskell Extending получил начальные
LineAndPoint/LineAndTwoPoints. Конвертер теперь создаёт действительную прямую,
а не ошибочно принимает её за две отдельные исходные точки. Witness переменной
длины восстанавливается в Geometry согласно той же параметризации.

Если алгоритм упал при обработке входа, BatchRunner теперь устанавливает
ненулевой exit code: ошибка не должна выглядеть успешной для очереди.

## Проверки

Полная сборка из закреплённых исходников с 26 патчами и обязательный smoke прошли.

- 392 C#-теста прошли, включая 10 новых: пять стартов с подбором гипотезы,
  два жёстких старта, исходный четырёхугольный сюжет пользователя и два
  контроля необходимости начального ограничения.
- 114 Python-тестов прошли. Проверяется чтение всех семи стартов из `.geo`.
- Haskell regression прошёл. Каталоги совпали: 72 построения, 136 альтернатив.
- Пять контрольных задач прошли независимый native truth checker.
  Extending сохранил необходимые определения в двух случаях и нашёл
  обобщение в трёх; прямой Haskell-вход `.geo` дал те же исходы.
- Все пять контрольных чертежей Geometry вычислила и подтвердила посылки.
- Выполнены восемь реальных коротких запусков генератора: все семь стартов
  и дополнительный исходный сюжет пользователя. У пяти нежёстких стартов
  подобраны условия; два жёстких старта завершились с `no-shape-freedom`.
- В пользовательском сюжете за пятисекундный бюджет поиска получены
  20 кандидатов до Extending. Все 20 `.geo` вычислены Geometry без ошибок,
  дополнительные посылки на них выполнены.

Короткие запуски проверяют работоспособность, а не олимпиадную сложность,
новизну или выигрыш скорости. В них использован `--no-check`, поэтому 20
кандидатов имеют статус unchecked, а не ready. Независимые проверки и
Extending проверены отдельно.

Первые пять кандидатов пользовательского сюжета при 5000 мс получили timeout.
Повторная проверка первого с 30000 мс нашла обобщение: пересечение диагоналей
достаточно заменить точкой первой диагонали. Есть 16 условных рисунков,
нарушающих исходное определение. Результат — rejected. Больший общий бюджет
также увеличивает разрешённое время на отдельное ослабление; поэтому первый
вариант успел решить задачу без обхода остальных. Время этого конкретного
повторного вызова — 1.82 с, это не оценка скорости генерации.

Машинные сводки: `reports/conditional-layouts-smoke.json`,
`reports/conditional-layouts-real-checks.json`,
`reports/conditional-layouts-user-30s.json`.

Воспроизводимый интеграционный тест:

```bash
python3 tests/check_conditional_layout_bundle.py \
  ./dist/geometry-suite-layouts ./layout-checks-001
```

Каталог результата должен быть новым. Тест проверяет native truth/Extending,
Haskell-вход, арифметику Geometry и запуск самого генератора.

## Ограничения

У LineSegment и LineAndPoint нет формы с точностью до подобия. Дополнительное
существенное условие не возникает от перемещения старта: поиск завершает этот
режим явно. Обычный поиск без дополнительных условий продолжает работать.

У RightTriangle условие может выделить отдельную форму. Восемь успешных
подборов могут соответствовать одному решению; distinctConditionSamples
считается отдельно с округлением параметров до шести знаков. Это контроль
различия результатов, а не доказательство независимости.

Области параметров конечны. Невырожденные объекты, строгая выпуклость и
различимость объектов проверяются, но охват всех компонент множества решений
не гарантирован. Условный Extending не становится формальным доказательством.
Стандартные чекеры сохраняют свою неполноту: unknown не считается сертификатом
сложности. Ранговое отсечение и алгоритм симметрий не менялись.
