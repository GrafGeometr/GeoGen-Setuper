# Проверки качества и аудит

Кампания `discover` автоматически включает стандартные доказательства и независимую проверку исходного утверждения. В ручном потоковом запуске:

```bash
./dist/geometry-suite-quality/geometry-suite run ./stories/example.txt \
  --output ./runs/example-quality --standard-checks --quality-checks --view
```

Проверки последовательно ищут короткое точное доказательство, запускают прежний Extending для поиска обобщений и проверяют исходное утверждение на новых картинках. Последний шаг не ослабляет условия и не заменяет определения. Он использует отдельный режим Haskell-проверяющего с воспроизводимым seed и точной арифметикой существующего геометрического движка. Это отдельная проверка от GeoGen, но она разделяет геометрические реализации с Extending.

## Что означают результаты

- `standard`: найден короткий вывод из поддержанных определений и условий. Сертификат сохраняется и перепроверяется. Фильтр неполон; отсутствие такого вывода не означает сложность.
- `ready`, проверка `sampled-valid`: исходная цель выдержала заданное число невырожденных проб. Это кандидат для просмотра, не доказанная новая теорема.
- `review`: найден контрпример, не хватило времени/допустимых картинок или проверка завершилась ошибкой. Причина, seed и при наличии координаты контрпримера сохраняются; кандидат доступен в общем списке Geometry, но не попадает в обычный список ready.
- `rejected`: прежний Extending нашёл обобщение. Прежние состояния ошибок, повторов и таймаутов также сохраняются.

Для кампаний по умолчанию проверяются 8 картинок с общим лимитом 2000 мс на кандидата. В `family.json` можно добавить:

```json
"quality": {"samples": 16, "milliseconds": 4000, "triangleDomain": "generic"}
```

`Triangle` по умолчанию проверяется как произвольный невырожденный треугольник, включая тупоугольные. Внутренние численные картинки GeoGen преимущественно остроугольные; это может скрывать зависимость от порядка точек и ветвей биссектрис. `triangleDomain: "acute"` явно ограничивает пробы остроугольными и добавляет отметку о необходимом условии. Исходные story при этом не переписываются. Исходные четырёхугольники проверяются выпуклыми, с сохранением циклического порядка вершин.

Отчёт также показывает глубину, существенные определения, неиспользуемые определения, поддержку по исходным точкам и знакомые мотивы: педальный/контактный треугольник, центры, дуги, точку Понселе. Само наличие известного мотива не служит доказательством и не отбрасывает задачу. Оценка `qualityScore` измеряет только компактность проверенного кандидата; красоту по GeoGen она не заменяет, сложность и мировую новизну не оценивает. Диспетчер учитывает эту оценку вместо простого числа находок.

## Проверить накопленные задачи

```bash
./dist/geometry-suite-quality/geometry-suite audit ./runs/my-family-001 \
  --samples 16 --milliseconds 4000 --workers 2 --diagrams
```

Аудит берёт `ready` и `review`, сохраняет отчёты в `quality-audit/` и не меняет их состояния в исходной очереди. Итог: `quality-audit/REPORT.md` и `summary.json`; у каждого кандидата — отдельный JSON и журнал. Для быстрой выборки добавьте `--limit 20`. `--triangle-domain acute` задаёт явное ограничение аудита.

`--diagrams` дополнительно вычисляет существующие `.geo` настоящим Geometry без окна. Проверяются ошибки разбора, бесконечные координаты, нулевые прямые и некорректные окружности; отсутствующая картинка тоже считается проблемой. Это не проверка читабельности рисунка или полноты интерфейса. Низкоуровневая команда:

```bash
"./dist/geometry-suite-quality/lib/geometry/bin/Geometry Desktop" --check-geo ./runs/my-family-001/geo
```

## Перепроверить кампанию новой сборкой

```bash
./dist/geometry-suite-quality/geometry-suite resume ./runs/my-family-001 --recheck
./dist/geometry-suite-quality/geometry-suite watch ./runs/my-family-001
```

При неизменном каталоге построений команда сохраняет резервную копию SQLite и прежние `.geo` в `archive/`, обновляет ключ проверяющей сборки и повторно обрабатывает сохранённые уникальные события, включая ранее отброшенные. Происхождение кандидатов сохраняется. При смене каталога построений нужна новая кампания. Прерванный внутренний DFS GeoGen с точного места не восстанавливается.

Аудит безопасно использовать для сравнения старого и нового отбора на одном корпусе. `resume --recheck` уже обновляет состояния и картинки; не запускайте его одновременно с работающей кампанией.

## Пока не реализовано

Нет полной проверки мировой новизны, общего геометрического объединения разных макросов, полной алгебры отношений/Чевы/Менелая, доказательства произвольного утверждения и точного возобновления фронтира GeoGen. Даже 100 успешных проб не заменяют доказательства. Сильнее всего текущий новый фильтр сокращает простые аффинные и метрические следствия; оставшиеся задачи с центрами и окружностями требуют дальнейшего разбора.
