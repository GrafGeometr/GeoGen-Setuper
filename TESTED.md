# Проверка 2026-11-05

Проверено в этой среде: Debian 13 x86_64, JDK 17, .NET SDK 7.0.410, GHC 9.6.6,
Gradle 7.2. Сборка выполнялась из свежих рабочих копий всех трёх репозиториев;
компиляторы и кэши зависимостей были подготовлены заранее.

- Все четыре компонента собраны; готовый комплект около 284 MiB.
- Все 116 существующих тестов GeoGen прошли.
- Все 7 проверок сборщика прошли (безопасность каталогов, переносимые настройки,
  обнаружение ошибки GeoGen, конфликт BAD_, защита результата от перезаписи).
- Контрольные примеры Extending: существенное построение сохранено,
  избыточное отбраковано.
- Полный run на input_projections.txt: GeoGen → 5 .geo → Extending, без таймаутов.
- doctor запущен на готовом комплекте, отсутствующих библиотек не обнаружено.
- Geometry Desktop запущен в Xvfb с программным рендерингом; окно и геометрический
  чертёж проверены на снимке экрана.
- Комплект перемещён в каталог с пробелами; smoke повторно прошёл.
- Итоговая повторная сборка прошла с --offline и --test.
- Исходные репозитории GeoGen, Geometry и GeometryExtending остались без изменений.

Первый прогон не проверял установку на пустой машине. Отдельная проверка
чистой Ubuntu 24.04 описана ниже; другие версии Ubuntu/Debian ещё требуют
собственных чистых прогонов.

## Исправление применения патча внутри клонированного сборщика

Воспроизведена ошибка: git apply из setup/.builder/work/GeoGen находил родительский
Git-репозиторий setup и пропускал пути патча, возвращая код 0. Из-за этого в комплекте
отсутствовали HiddenPoints и input_hidden_points.txt.

Рабочая копия GeoGen теперь получает собственный локальный .git перед применением
патча; наличие контрольного примера проверяется до компиляции. Добавлена реальная
проверка с вложенным Git-репозиторием. Она проверяет изменение содержимого файла
и отсутствие записи в исходники родительского репозитория.

Полная сборка из вложенного каталога Git-репозитория прошла с --offline --test:
136 тестов GeoGen, 8 тестов сборщика, обычный и HiddenPoints smoke-прогоны.

## Потоковая обработка и Geometry — локальная версия 2026-11-06

Ниже приведены проверки потоковой версии перед публикацией.

- Полная сборка из закреплённых чистых исходников с тремя патчами прошла
  с --offline --test: 136 тестов GeoGen; 17 Python-проверок сборщика/очереди.
- Пример input_projections: 27 отдельных событий, 27 готовых .geo; финальная
  подборка лучших по-прежнему содержит 5 теорем. Две готовые задачи были
  сохранены до завершения настоящего процесса GeoGen.
- Реальный Ctrl+C во время обработки: GeoGen остановлен, очередь сохранена;
  resume обработал оставшееся, время завершения уже готовых задач не изменилось.
  В интерфейсе завершение очереди после остановленного поиска отмечается отдельно.
- Реальный Extending --check-file вернул error для неверного входа и timeout
  для большого входа при лимите 1 мс; контрольные accepted/rejected тоже проверены.
- Проверены незавершённые события, точные повторы, рестарт очереди, блокировка
  двух обработчиков одного каталога, ошибки/сбои/таймауты и частичная конвертация.
- Geometry запущен в Xvfb с программным рендерингом до появления каталога запуска;
  список наполнился и чертёж открылся без перезапуска. Снимок просмотрен: текст
  списка и подписи чертежа читаются благодаря встроенному DejaVu Sans.
- HiddenPoints проверен и в новом потоке: один результат примера прошёл Extending
  и конвертацию. Старые пакетные smoke-проверки также прошли.

resume восстанавливает только обработку полученных событий, не дерево поиска.
Устранение повторов в потоке сравнивает строки конфигурации и утверждения,
а не произвольную геометрическую эквивалентность.
