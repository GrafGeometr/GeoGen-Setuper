# Правила кастомных построений

Сборщик остаётся на закреплённом форке GeoGen/.NET 7. Правила и тесты поставляются
патчами `custom-constructions-geogen.patch` и `custom-construction-rules.patch`.
Ниже описаны связи, которые используются для исключения базовых фактов из выдачи.
Это не полный решатель геометрии и не раскрытие всех макросов в генераторе.

## Что знает прувер

Обозначения: ABC — треугольник, P — дополнительная точка; середина стороны,
центр, прямая или окружность в утверждении должны быть доступны пруверу.
Введения вспомогательных объектов помогают получить часть таких объектов.

| Построение | Добавленные связи |
| --- | --- |
| `IncircleTangentPoint` | Принадлежность вписанной окружности; проекция инцентра на сторону и перпендикулярность радиуса стороне; равенство касательных из одной вершины. |
| `HumptyPoint` | Проекция ортоцентра на медиану; принадлежность медиане; коллинеарность с вершиной и серединой противоположной стороны. |
| `DumptyPoint` | Проекция центра описанной окружности на симедиану; принадлежность симедиане; коллинеарность с вершиной и основанием симедианы. |
| `HOPoint` | Отражение основания высоты относительно середины противоположной стороны; коллинеарность и равенство соответствующих отрезков. |
| `TangentLinesIntersection` | Принадлежность обеим касательным; инверсия середины противоположной стороны относительно описанной окружности; принадлежность симедиане. |
| `Symedian` / `SymedianEnd` | Симедиана проходит через пересечение соответствующих касательных и своё основание. |
| `BisectorEnd` | Принадлежность внутренней биссектрисе; коллинеарность с вершиной и инцентром. |
| `ExternalBisectorEnd` | Принадлежность внешней биссектрисе; коллинеарность с вершиной и соответствующим вневписанным центром. |
| `RadiusLine` / `RadiusLineEnd` | Принадлежность центра описанной окружности и основания радиальной прямой; определение основания через пересечение с противоположной стороной. |
| `Gergonne` | Прямые через вершины и точки касания вписанной окружности; определение как пересечения двух таких прямых. |
| `Nagel` | Прямые к точкам касания соответствующих вневписанных окружностей; прямые к отражениям точек касания вписанной окружности относительно середин сторон; изотомическое сопряжение Жергонна. |
| `Lemoine` | Принадлежность симедианам и прямым к их основаниям; изогональное сопряжение центроида. |
| `Isogonal` | Отражение луча относительно биссектрисы, повторное сопряжение возвращает исходную точку; распознаются пары центроид–Лемуан и центр описанной окружности–ортоцентр. |
| `Isotomic` | Следы сопряжённых чевиан симметричны относительно середины стороны; повторное сопряжение возвращает точку; распознаётся пара Жергонн–Нагель. |
| `Antigonal` | Окружности через сторону и отражение исходной точки относительно этой стороны; определение через второе пересечение соответствующих окружностей. |
| `PonceletPoint` | Принадлежность окружностям девяти точек треугольников из трёх вершин четырёхугольника; цикличность с тремя соответствующими серединами сторон. |
| `FeuerbachPoint` | Принадлежность вписанной окружности и окружности девяти точек; связь с `PonceletPoint(A,B,C,Incenter(A,B,C))`. |
| `QuadrilateralCentroid` | Середина отрезка между серединами противоположных сторон, для всех разбиений на пары; коллинеарность с вершиной и центроидом остальных трёх вершин. |
| `FPC` | По фактическому определению в форке: окружность через ортоцентр, середину BC и основание высоты из A. Она же окружность с диаметром «ортоцентр–середина BC»; на ней лежит соответствующая Humpty-точка. |
| `Harmonic` | По фактическому определению в форке: отражение результата инверсии относительно BC. Связь с инверсией задаётся явно. |
| Шесть семейств `*Middle` | Связи со средней линией, серединами сторон, определяющей прямой и половинами отрезка до основания, добавленные предыдущим патчем. |
| Инверсия и центры гомотетии | Коллинеарность с доступными центрами окружностей, добавленная предыдущим патчем. |

Определения посредством `EqualObjects` используются для отождествления разных
способов записи одной точки или окружности, а не для признания всех похожих
конфигураций эквивалентными.

## Проверки и ограничения

- В дополнительном наборе 53 файла с 62 заключениями и 22 правила введения
  вспомогательных объектов. Новые безусловные заключения проверяются отдельно
  на пяти независимых численных картинках.
- Есть проверки настоящего вывода прувера в строгом режиме: без эвристики
  «можно сформулировать без лишнего объекта». Проверяются также неверные аналоги
  утверждений и отсутствие геометрически неверных применений новых правил.
- Режимы с построением доказательств и без него проверяются на одних фактах.
  Исправлена работа с двумя записями одной прямой/окружности: явным построением
  и заданием через точки. `EqualObjects` сохраняет объекты целиком.
- Введения объектов конечны и ограничены существующим механизмом прувера.
  Наличие правила не гарантирует, что любая длинная цепочка вспомогательных
  построений будет найдена автоматически.
- `Harmonic` в текущем форке определён через шаблон `Triangle` и не строится на
  трёх коллинеарных входных точках. Поэтому правило классического гармонического
  деления прямой здесь не заявляется. Изменение области определения этого
  построения — отдельная задача; правила не меняют его формулу или ограничения.

Набор загружается автоматически после сборки. Старые результаты не пересматриваются:
для сравнения запустите прежний сюжет обновлённым комплектом в новом каталоге.
